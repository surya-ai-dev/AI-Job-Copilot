# Resume Matching & Optimization Engine Module

This module runs the AI optimization loops, checks ATS keyword matches, computes readability scores, and rewrites summary and skills sections while ensuring zero fabrication.

---

## 1. Resume Optimization loop Workflow

The diagram below shows the matching, tailoring, and Critic auditing sequences:

```mermaid
sequenceDiagram
    autonumber
    actor User as Job Seeker
    participant API as FastAPI Router
    participant Svc as ResumeOptimizationService
    participant Loop as Optimization Loop (Max 3 Runs)
    participant Compiler as Document Compiler (DOCX/PDF)
    participant Repo as ResumeOptimizationRepository
    participant DB as PostgreSQL DB

    User->>API: POST /resume/optimize (job_analysis_id)
    API->>Svc: optimize_resume(user_id, job_analysis_id)
    Svc->>Svc: Fetch active master resume & job analysis
    Svc->>Svc: Initialize Optimization Loop
    
    loop Optimization Cycle (Iteration <= 3)
        Svc->>Loop: Tailor summary & order technical skills
        Loop->>Loop: Run Critic validation check
        
        alt Zero-fabrication check passes & ATS score >= 90
            Svc->>Svc: Break loop (Target Achieved)
        else Validation check fails (e.g. fabricated skill detected)
            Svc->>Loop: Feed error logs back to Optimizer for re-run
        end
    end

    Svc->>Compiler: Compile optimized summary & skills into PDF
    Compiler-->>Svc: File path on disk
    Svc->>Repo: create_optimization(domain_opt)
    Repo->>DB: Save optimization metrics
    DB-->>Repo: Saved record details
    Svc-->>API: ResumeOptimizationResponse payload
    API-->>User: HTTP 201 Created (Tailored JSON)
```

---

## 2. API Endpoint Specification

*   `POST /api/v1/resume/optimize`: Trigger matching and optimization loop to tailor the master resume for a job posting.
*   `GET /api/v1/resume/optimize/history`: List all optimization reports previously generated by the current user.
*   `GET /api/v1/resume/optimize/{id}`: Retrieve details for a specific optimization report.
*   `GET /api/v1/resume/optimize/report/{id}`: Retrieve readable match audits and recommendation summaries.
*   `GET /api/v1/resume/optimize/download/{id}`: Download the optimized PDF resume file.

## 3. Strict Optimization & Preservation Rules

To protect the candidate's professional integrity, the optimization engine enforces the following constraints:

*   **Honesty Guarantee**: The AI is strictly prohibited from fabricating achievements, experiences, projects, or certifications. Skills not present in the master resume are listed in the "Unmatched Skills Gaps" report but never added to the tailored resume.
*   **Allowed Modifications**: The AI can only modify the resume heading, professional summary statement, technical skills grouping and ordering, and the wording of existing bullet points to align with job keywords.
*   **Immutable Properties**: Name, contact details, companies, job titles, dates of employment, and degree names must remain completely unchanged.
*   **Layout Preservation**: The system applies text updates without altering the original DOCX layout structure, margins, font styles, or page configurations.
